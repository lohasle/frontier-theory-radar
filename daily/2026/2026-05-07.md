## 4. 今日深挖论文

- **一句话本质：** 推测解码的最优推测长度 γ 应随压缩级别动态调整，而非固定为 4。
- **底层问题：** LLM 推理延迟是生产部署核心瓶颈，推测解码是最有前景的加速手段，但现有系统忽略了压缩级别对最优 γ 的显著影响。
- **新命题 / 新方法 / 新证据：** 用轻量 MLP 从草稿模型提取置信度和熵信号，自适应选择 γ，在 5112 条记录上验证 56% 相对提升（p<0.001）。
- **研究位置：** 源头论文。首次系统揭示量化级别对推测解码 γ 的影响，并提出端到端解决方案。
- **工程可验证性：** 暂缺代码链接，但方法描述清晰，可从 profiling 数据 + MLP 训练侧做最小验证。任何使用推测解码的推理框架（vLLM、TensorRT-LLM）都是潜在集成目标。
- **趋势关联：** 推理优化从固定策略转向自适应/学习型策略的大趋势，与 Medusa 多头推测、Eagle 特征级推测互补。
- **长尾价值：** 即使短期不部署，SpecKV 的 profiling 方法和数据集可作为推理优化的基准资产。
- **启发：** 在量化模型上部署推测解码时，应先 profile 最优 γ 而非直接使用默认值。部署同一模型的不同量化版本需要不同的推测策略。
