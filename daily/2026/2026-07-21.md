## 7. 启发

### 对推理服务系统的启发
MoE 已成主流架构，但'显存墙'正取代'算力墙'成为服务瓶颈。PagedWeight 揭示：在 KV-cache 密集场景下，不应把权重精度当作静态常量，而应作为运行时可调的资源杠杆——冷门专家降精度、省下的显存还给 KV cache 池。这种'精度换容量'的帕累托调度思路可迁移到任何显存受限的推理服务。

### 对 Agent RL 训练工程的启发
Agentic RL 后训练阶段的优化器选择是被低估的工程杠杆。When Does Muon Help 给出了一条具体线索：仅对 2D 隐藏权重矩阵施用 Muon（不对其他参数），在稀疏奖励设定下可能显著优于 AdamW。'选择性优化器策略'——对不同参数组用不同优化器——本身是一种可迁移的训练工程模式。

### 对多模态评测的启发
ActiveVision 揭示当前多模态评测的盲点：依赖单帧快照的 benchmark 无法测量'主动观察'能力。人类视觉是闭环的（注视由中间假设引导），MLLM 是否具备这种闭环感知？多模态 Agent 评测应增加'需要多帧/多区域主动聚焦才能解决'的任务维度。

### 对安全治理的启发
CAV CVE 把 LLM 做非结构化→结构化威胁情报抽取具体化了。对任何用 LLM 做文档→结构化数据的 pipeline，都应默认评估幻觉率、准确率与对模糊输入的鲁棒性，而非只看'能生成结构化输出'。

### 对系统设计（含雷达自身）的启发
数据新鲜度连续失真 3 天后今日恢复，但根因（抓取不按日期过滤、不跨日去重）未修。系统的鲁棒性不应依赖'数据恰好恢复'，而应靠防御性工程——让'无新论文'成为可被显式报告的状态，而非用旧批次填满版面。此项前 3 份日报已推荐，今日数据恢复不改变其必要性。
